# Условие: число больше 100

Напишите цикл, который предлагает с помощью `prompt` ввести число, большее 100.

## Правила

1. Если посетитель ввёл число, не большее 100 — попросить ввести ещё раз, и так далее.
2. Цикл спрашивает число, пока посетитель не введёт число, большее 100, либо не нажмёт «Отмена» (Esc).
3. Предполагается, что посетитель вводит только числа; обработка нечисловых строк необязательна.

## Ожидаемое поведение

| Вход             | Результат                          |
| ---------------- | ---------------------------------- |
| `101` и больше   | цикл завершается                   |
| `100`, `0`, `-5` | снова запрос ввода                 |
| пусто / Esc      | цикл завершается (значение `null`) |
