_**JavaScript**_

**Переменные**

В названии переменной могут быть: буквы, цифры, $, _. Но первый символ не цифра.
Если имя из нескольких слов используем верблюжий регистр
(myVeryLongName).
Нельзя использовать в качестве имен:
let, class, return, function.
apple и APPLE это разные переменные.

**var** - устаревшее использование (старый образец до 2015г) _Минусы:_ к переменной можно обратиться еще до ее обьявления и пробивает блоки кода (видны во всей функции)

**let** - переменная которую можно изменить (современное использование с 2015г)

**const** - переменная, которую нельзя изменить.

_Обьявление переменной_ - сообщение компьютеру выделить память для хранения данных и закрепить за этой областью памяти определенное имя (идентификатор).

**Область действия** - это текущий контекст выполнения в котором значение и выражение видны или могут быть использованы в качестве ссылок. Повторно объявлять переменные (let, const) в одной области видимости нельзя, но можно обьявлять в дочерних областях видимости.
**Глобальный охват** - это когда переменная видна во всех областях видимости.
**Блочная область видимости**- это блок, если переменная объявлена внутри, то за границами её не существует.
**Поднятие объявления** - это механизм JS, когда объявление переменных функций или классов перемещается движком наверх их области видимости еще до того, как код начнет выполняться.

**_Типы данных_**

есть 8 _основных типов_ данных:

- _примитивные_ (храняться в переменной, значение) 7шт
- _сложные_ (хранят ссылку на место в памяти где лижат данные) 1шт

                    **1.Число (Number)**

Число - отображает целые числа и числа с плавающей запятой.

Infinity - математическая бесконечность всегда больше любого числа. Получаем при деление на ноль.

- Infinity - бесконечность с минусом.

NaN - вычислительная ошибка, результат некорректной математической операции.
NaN**0 = 1

                **2.BigInt**

это очень большие числа, больше диапазона number. Создаются путем добавления n в конце целого числа.

                **3.String (строка)**

Должна быть заключена в кавычках.
" " - Двойные
' ' - одинарные
`   ` - обратные.
Обратные кавычки расширяют функциональность.
Позволяют встраивать переменные и выражения в строку заключая их в ${ }.

Выражение внутри ${ } dычисляется и результат становится частью строки.

                **4.Булево значения (логический тип)**

Обычно название такой строки с is.
Да/нет true/false
Пример: const isActive = true
Часто используется, когда есть ветвление.

                **5.Нулевое значение (null)**

Это пустота

                **6.Неопределенное значение (undefined)**

Значение не присвоено

                **7.Символ (symbol)**

Уникальный идентификатор для создания уникальных скрытых свойств объектов, которые никто случайно не перезапишет.

                **7.Объекты**

Объекты - это коробка, которая может хранить в себе коллекции других данных и сложные сущности.
Объекты объявляются через фигурные скобки {}.
К объекту относится:

- массивы Arrays (пишется в []),
- функции Function (используем return, чтобы функция что-то вернула),
- даты Date,
- ошибки Error,
- регулярные выражения Reg Exp.

**Взаимодействие с браузером (функции браузера) alert, prompt, confirm**

Модальные методы имеют 2 ограничения:

1.  расположение окон определяет браузер (обычно центр)
2.  визуальное отображение окон зависит от браузера, и мы не можем изменить их вид.

**alert** - вызывает модальное окно, пользователь не может использовать интерфейс, пока взаимодействует с окном.

**prompt** - функция браузера, которая принимает 2 аргумента.

result = prompt(title,[default]);

title - текст для отображения в окне.
default - необязательный второй параметр, который устанавливает начальное значение в поле для текста в окне.
Вызов prompt Возвращая текст, указанный в поле для ввода или null, если вод отменен пользователем.

```
let age = prompt ('Сколько тебе лет?',100);
alert (`Тебе ${age} лет!`)// Тебе 100 лет!
```

**confirm**

confirm - Эта функция отображают модальное окно с текстом и кнопками ОК и Отмена. Результат true - если нажата кнопка OK, в других случаях - false.
result = confirm (question);
let isBoss = confirm ('Ты здесь главный?');
alert (isBoss);// true если нажата ОК
