# AGENTS.md

Инструкции для агентов в этом репозитории.

## О проекте

Учебный репозиторий по JavaScript (JS 2026): примеры, задачи и решения.

## Структура папок

```
examples/    примеры кода из уроков (.html, .js, .mjs)
tasks/       условия задач (task-*.md)
solutions/   решения задач (solution-*.html/.js)
notes/       конспекты и рабочие заметки (*.md)
.opencode/   конфигурация opencode (скиллы, тулы, агенты)
.vscode/     настройки редактора (автоформат при сохранении)
```

Новые файлы класть в соответствующую папку, не в корень.

## Команды

- `npm run format` — форматировать всё через Prettier;
- `npm run format:check` — проверить форматирование;
- `npm run lint` — ESLint (JS) + HTMLHint (HTML);
- `npm run fix` — форматирование + автоисправления ESLint.

## Форматирование и линты

- Prettier: `.prettierrc.json`, игнор — `.prettierignore`.
- ESLint (flat config): `eslint.config.mjs`, `@eslint/js` recommended +
  `no-var`, `prefer-const`, `eqeqeq: smart`, глобы браузера.
- HTMLHint: `.htmlhintrc`.
- Автоформат при сохранении: `.vscode/settings.json` (Prettier + ESLint
  fixAll) и `.editorconfig`.
- Перед коммитом прогонять `npm run format:check && npm run lint`.

## Git

- **Не делать коммиты без явного ревью пользователя.** Сначала показать diff,
  получить подтверждение, только потом коммитить.
- **Не пушить.** Пуш выполняется исключительно по прямой команде пользователя.
- Перед коммитом всегда проверять `git status` и `git diff`.
- Сообщение коммита — короткое, в повелительном наклоне, без эмодзи.

## Именование файлов

Международные правила (kebab-case):

- только строчные латинские буквы, цифры, дефисы;
- без пробелов, без кириллицы, без спецсимволов;
- глагол/существительное + предмет, например `task-login-check.md`;
- расширение по содержимому (`.md` — условие/документация, `.html` —
  полноценная HTML-страница, `.js`/`.mjs` — скрипт);
- не начинать и не заканчивать имя дефисом, не использовать `--`.

## Код

- `'use strict'` в начале скрипта.
- Согласованный отступ — 2 пробела.
- Переменные — `let`/`const`, без неявного приведения типов там, где можно
  обойтись строгим сравнением (`===`), если задание не требует иного.
- Комментарии — только если просят.

## Скиллы и инструменты

- Скилл: `.opencode/skills/<name>/SKILL.md`, фронтматтер `name` + `description`,
  `name` совпадает с именем папки, формат `^[a-z0-9]+(-[a-z0-9]+)*$`,
  `description` 1–1024 символов.
- Инструменты: `.opencode/tools/<name>.ts`, экспорт по умолчанию через
  `tool()` из `@opencode-ai/plugin`; имя файла = имя тула.

## Режим работы

- Плановый режим: только чтение и анализ, никаких изменений файлов.
- После изменения конфигурации opencode (агенты, скиллы, `opencode.json`)
  попросить пользователя перезапустить opencode.
