# Условие: проверка логина и пароля

Напишите код, который спрашивает логин с помощью `prompt`.

## Правила

1. Если посетитель вводит «Админ» — `prompt` запрашивает пароль.
2. Если ничего не введено или нажата клавиша Esc — показать «Отменено».
3. В любом другом случае — отобразить «Я вас не знаю».

## Проверка пароля

- Введён пароль «Я главный» → вывести «Здравствуйте!».
- Иначе → «Неверный пароль».
- Отмена или пустой ввод → «Отменено».

## Ожидаемое поведение

| Вход                    | Результат         |
| ----------------------- | ----------------- |
| `Админ` + `Я главный`   | «Здравствуйте!»   |
| `Админ` + другой пароль | «Неверный пароль» |
| `Админ` + пусто / Esc   | «Отменено»        |
| пусто / Esc             | «Отменено»        |
| другой логин            | «Я вас не знаю»   |
